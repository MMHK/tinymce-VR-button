🎮 TinyMCE VR Button Plugin

for 720yun.com VR 360° Content

📖 使用说明 / Instructions

  • 1️⃣
    点击工具栏 VR 图标
    Click the VR icon in the toolbar
  • 2️⃣
    输入 720yun 链接
    https://720yun.com/t/xxxxx
  • 3️⃣
    插入 VR 360° 按钮
    A VR button will be inserted into the editor
  • 🖥️
    Desktop: 展开 inline iframe 视图 (800×600px) Overlay
  • 📱
    Mobile: 新窗口打开 VR 链接 New Tab
